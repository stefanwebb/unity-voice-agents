Voice Agents (`com.stefanwebb.voiceagents`) is a Unity 6 package that lets you add fully local, AI-powered voice interactions to your game. It connects Unity to a local speech-to-text (STT) server and a local LLM chat server over named pipes, and exposes everything as typed events on a lightweight event bus — so your gameplay code stays clean and decoupled from the transport layer.

Use it to build intelligent NPCs that understand spoken player input, voice-driven game interfaces, interactive narrative characters, and more — all running on your own hardware without sending data to any cloud service.

## How It Works

When a player speaks into the microphone, the audio is captured by a local STT server running outside Unity. That server transcribes the speech and sends the result back over a named pipe. The `SttClient` component receives the transcription and raises typed events on the `EventBus`. The `ConversationManager` listens for confirmed input and sends the full conversation history to the local LLM chat server via `ChatClient`. The LLM reply streams back token-by-token, also through the event bus, where your UI components and game logic can consume it.

```
Microphone ─► named_pipes.stt server ─┐
                                      │  /tmp/tool-stt, /tmp/tool-chat (FIFOs)
vLLM / any OpenAI-style LLM ◄─ named_pipes.chat server ─┘
                                      ▲
                                      │ ToolClient (JSON lines)
                                      ▼
  SttClient ──────► EventBus ◄────── ChatClient
                      ▲   │
      ConversationManager │  SttTranscriptionDisplay / ChatDisplay / SttStateIcon
                      your scripts (raise commands, subscribe to events)
```

## Requirements

- **Unity 6000.0** or later (requires .NET Standard 2.1 for `System.Text.Json`)
- **macOS or Linux** — the named-pipe transport uses POSIX FIFOs (`mkfifo`)
- **Running STT and chat servers** from the companion `named_pipes` Python package
- **TextMeshPro Essentials** imported into your project (Window ▸ TextMeshPro ▸ Import TMP Essential Resources)

<Note>
  Text-to-speech (TTS) is not yet implemented. The package currently covers speech input and LLM chat response only.
</Note>
