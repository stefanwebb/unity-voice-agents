Voice Agents (`com.stefanwebb.voiceagents`) brings fully local, AI-powered voice interactions to Unity 6. Connect a local speech-to-text server and a local LLM to your game through a clean typed event bus — no cloud dependency, no API costs, and no data leaving your machine.

## Getting Started

<Steps>
  <Step title="Install the package">
    Open **Window ▸ Package Manager**, click **+ ▸ Add package from git URL**, and enter `https://github.com/stefanwebb/unity-voice-agents.git`.
  </Step>
  <Step title="Start the local servers">
    Run the `stt` and `chat` tool servers from the `named_pipes` Python package so `/tmp/tool-stt` and `/tmp/tool-chat` exist.
  </Step>
  <Step title="Add components to your scene">
    Add `SttClient`, `ChatClient`, and `ConversationManager` to a GameObject, then add the UI helper components for live feedback.
  </Step>
  <Step title="Raise and subscribe to events">
    Use `EventBus.Raise()` and `EventBus.SubscribeTo()` from any script to start listening and respond to speech and LLM tokens.
  </Step>
</Steps>
